# Local Privacy Redactor

100% lokale Privacy-Redaction-App mit:
- OpenAI Privacy Filter
- Streamlit
- PDF/DOCX/XLSX/TXT Support
- Regex + ML Detection
- Keine Cloud
- Keine API

## Features

- Sensitive Daten erkennen
- Dokumente redacten
- Download bereinigter Dateien
- Komplett lokal

## Tech Stack

- Python
- Streamlit
- Transformers
- PyMuPDF
- pandas
